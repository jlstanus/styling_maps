# Bibliothèque SVG

Sources vectorielles communes aux styles. Utiliser SVG 1.1 simple, sans polices externes ni fonctionnalités propriétaires lorsque possible.

- `markers/` : pictogrammes ponctuels.
- `patterns/` : motifs répétitifs.
- `templates/` : exemples et modèles paramétrables.

Les SVG de `templates/` illustrent les paramètres QGIS `param(fill)`, `param(outline)` et `param(outline-width)`, avec des valeurs de repli. Ils restent des fichiers SVG ; les paramètres `param(...)` sont une extension interprétée par QGIS et peuvent ne pas être remplacés par les autres moteurs.
